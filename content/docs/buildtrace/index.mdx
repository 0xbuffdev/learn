BuildTrace helps Rust teams review what dependency build scripts and procedural macros do while Cargo builds. It inventories the build-time code in a dependency graph and is being developed to record file access, child processes, and network connections for review in CI.

## What it is designed to observe

BuildTrace focuses on build-time code that normally runs with the same privileges as the compiler:

- Build scripts and procedural macros in a Cargo dependency graph.
- Planned file, process, and network recording during Linux builds.
- Reports designed to identify the code responsible for each observed operation.

The planned first release targets Linux and uses `ptrace` for selected operations. Reports are designed to include confidence and limitation information when attribution or trace coverage is incomplete.

## Try the inventory command

BuildTrace is pre-alpha. The inventory command is implemented; recording and policy comparison are still in development. Clone the repository and run the inventory against a Cargo project:

```bash
git clone https://github.com/christophersesugh/buildtrace
cd buildtrace
cargo run -p buildtrace-cli -- inventory
```

Inventory lists build scripts and procedural macros without executing them. The intended workflow also includes recording a build, reviewing a source-pinned policy, and comparing later builds against that policy:

```bash
cargo buildtrace record -- cargo check --workspace
cargo buildtrace propose > buildtrace.toml
cargo buildtrace diff --policy buildtrace.toml
```

These latter commands describe the planned workflow and are not implemented yet.

## Scope and limits

The planned recorder will produce evidence about build-time behavior. BuildTrace does not grant permissions, sandbox a build, or prove a dependency is safe when a report is clean. The initial release targets Linux and does not cover application runtime behavior or every operating system. It is designed to keep traces local and avoid uploading them.

Raw traces can contain sensitive paths and command data. BuildTrace is designed to avoid recording environment-variable values by default, redact credentials from arguments and URLs, and label uncertain attribution rather than present it as complete.
